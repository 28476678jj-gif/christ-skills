# 每日灵修默想

## 用途

陪一个人在一天当中安静十分钟：读一小段经文，慢慢思想，带着具体的一件事离开。产出短，不分析大问题，不铺陈知识，只做三件事：经文说了什么、它今天对我说什么、我今天要做什么。同时给出祷告的方向，让人知道怎么开口。

## 触发场景

- "腓立比书 4:6-7 灵修"、"今天读诗篇 23，帮我默想"
- "给我今天的灵修"、"今天灵修用什么经文"（由技能按当日日程或书卷顺序建议一段）
- "心里乱，想安静一下"、"早上想先读点经文再开工"
- 不适用：要研究一段经文的意思（用解经技能）；要预备讲章或小组分享稿（用讲道技能）；要查某个主题的整本圣经脉络（用主题查经技能）。

## 输入与输出

输入：

- 可选：经文范围。不给时由技能按当日日期从读经日程取，或建议一段适合当日处境的短经文（三到十节为限），并说明为什么选这段。
- 可选：当日处境（疲乏、焦虑、感恩、有决定要做、与人有摩擦）。知道处境时，默想的落点随之调整，但不替经文换意思。

输出（markdown，约 600 至 1200 字）：

1. 经文（检索所得原文，标注译本）
2. 安静（一两句把人从忙碌里拉出来的话，不长篇说教）
3. 读三遍（第一遍看字面，第二遍注意重复与转折的词，第三遍把其中一个词读慢）
4. 默想（这段经文显明神是怎样的一位；它照出我今天真实的情形；它今天要我做的那一件事）
5. 祷告指引（三个方向，给出开头句，不写完整祷词，除非用户要求）
6. 今日一步（一件今天就能做的具体小事）

## 工作流程

1. **确认经文与处境。** 用户给了就用用户的，没给就按日程或书卷顺序建议一段，并说清选它的理由（如当日处境对应）。
2. **取经文原文。** 凡引用经文必须先检索取得原文（用户本地 biblemate 数据库或本库 `data/bibles/`），**不得凭记忆引用**。把原文完整放在开头，标注译本。
3. **写安静段。** 一两句，从人的真实状态切入（忙、乱、累、睡不着），不用感叹句，不喊口号。可参考诗篇 46:10 所写的"你们要休息，要知道我是神"。
4. **带读三遍。** 每一遍给一个具体动作，第二遍点出经文里的重复词、转折词或动词，第三遍挑一个词让人停住。不解释太多，留空间给人自己读。
5. **写默想。** 围绕三个问题写，每段不超过一百五十字：神是怎样的一位；我今天的真实情形；今天要我做的那一件事。回答必须挂在经文的词句上，不许飘到经文之外做道德发挥。
6. **祷告指引。** 给三个方向（如：为刚才读到的那一位感谢；把今天压着的那件事说出来；为一个人代求），每个方向给一句开头的话。祷告要基于刚读的经文，不套公式。
7. **今日一步。** 一件具体、当天可完成、与经文直接相关的小事（打一个电话、停止一件正在做的事、写下一个人名、读一节经文给某人听）。不列三条清单，只给一件。
8. **自检。** 全部引用过 `tools/verse_check.py`；语气是否安静；有没有越界给专业意见。

## 经文依据

- 诗篇 1:2-3：「惟喜爱耶和华的律法，昼夜思想，这人便为有福！他要像一棵树栽在溪水旁，按时候结果子，叶子也不枯干。凡他所作的尽都顺利。」默想不是赶进度，是把一段话反复思想到扎根，这是本技能全篇的方法根据。
- 诗篇 46:10：「你们要休息，要知道我是神！」灵修的第一步是停下来，不是多懂一点道理。
- 腓立比书 4:6-7：「应当一无挂虑，只要凡事借着祷告、祈求，和感谢，将你们所要的告诉神。神所赐出人意外的平安，必在基督耶稣里保守你们的心怀意念。」默想通顺向祷告，这两节是祷告指引部分的根据。
- 马太福音 11:28：「凡劳苦担重担的人可以到我这里来，我就使你们得安息。」灵修的入口是主自己，不是方法。
- 希伯来书 4:16：「所以，我们只管坦然无惧的来到施恩的宝座前，为要得怜恤，蒙恩惠，作随时的帮助。」这句话决定了祷告指引的语气：坦然，不是小心翼翼。

## 争议标注

- 灵修方法本身无争议级内容。
- 当日经文若触及争议议题（如预定、恩赐、末世），默想只取经文对今日生命的直接光照，不展开宗派论证，并在文末注明该议题存在不同理解，建议读者参照本教会教导。
- 灵修中出现的异象、感动、特殊经历叙述，一律不作教义依据；本技能不产出预言性内容。

## 质量校验清单

- [ ] 经文来自检索，文件通过 `tools/verse_check.py`
- [ ] 全篇 600 至 1200 字，读完不超过十分钟
- [ ] 默想三段分别回答了神、我、今天要做什么，且都挂在经文词句上
- [ ] 祷告指引基于刚读的经文，无空泛套话
- [ ] 今日一步只有一件，具体、当天可做
- [ ] 无说教口气、无感叹号堆砌、无专业意见越界
- [ ] 通过 `tools/lint_skill.py`

## 免责与边界

- 本技能产出为个人灵修材料，不是心理咨询或医疗建议。用户若有持续的抑郁、失眠、伤害自己的念头，应在文中温和建议其寻求专业帮助与本教会牧者，灵修材料不能替代这些。
- 灵修中的感受与体会属于个人领受，不构成教义判断，也不构成对他人的指示。
