# 经文引用格式规范化

## 用途

同一份文档里的经文引用常常写得五花八门：有的用全名有的用简称，冒号有半角有全角，空格时有时无，繁简混排，范围连字符用波浪号。本技能把这些统一成一种规范写法，只动标注，不动正文引文。

它是纯文本工具：识别、替换、报告。不解释经文，不判断引用是否恰当。

## 触发场景

- "把这篇里的经文引用格式统一一下"、"简称都换成全名"
- 繁简混排的稿件要清理书卷名
- 发布前做一次格式归一，配合引用校验器一起用
- 不适用：要核验引用有没有写错（那是引用校验器的活）；要改经文内容。

## 输入与输出

输入：

- 必需：文件或目录（递归处理 `.md`）
- 可选：`--style full` 用书卷全名（默认），`--style abbr` 用规范简称；`--inplace` 直接改写文件（默认只预览不改写）

输出：

- 默认预览模式：列出每处将要发生的改动（原文 → 规范写法），并给出汇总
- `--inplace` 模式：改写文件，并打印改动总数

## 工作流程

1. **先预览，再决定。** 书卷名与章节的识别一律依据六十六卷映射表，不由模型凭记忆判定。默认不改文件，先看清单，确认没有误伤（例如正文里出现的同名词汇被当成书卷名）。
2. **选择风格。** 对外发布、正式文稿建议 `--style full`（约翰福音 3:16）；内部笔记、篇幅受限建议 `--style abbr`（约 3:16）。同一份文件内保持一致。
3. **执行。**

```bash
# 预览（默认，不改写）
python scripts/format_references.py 文档.md

# 统一为全名并改写
python scripts/format_references.py 文档.md --style full --inplace

# 整个目录，统一为简称
python scripts/format_references.py 目录/ --style abbr --inplace
```

4. **复核。** 改完用引用校验器跑一遍，确认引用仍然全部通过；同时人工扫一眼改动清单，确认没有把正文文字误当引用改写。
5. **备份（可选）。** 首次对重要稿件批量改写前，先提交一次版本或复制备份，便于回滚。

## 规范化规则

- 书卷名：按六十六卷映射表识别，繁体写法（如「約翰福音」）与英文缩写（如 `Jn`）都能识别，输出时按指定风格统一
- 章与节之间用半角冒号：`约翰福音 3:16`
- 书卷名与章号之间保留一个空格
- 范围用半角连字符：`约翰福音 3:16-18`；跨章：`约翰福音 3:16-4:2`
- 只替换引用标注本身，引文内容一字不动

## 经文依据

本节不适用。本技能属 neutral 级工具，不作出任何教义主张，因此没有经文依据章节的内容。

## 争议标注

不适用。书卷简称存在传统差异（例如「约一」与「约翰壹书」），本工具按映射表统一，不裁定哪种传统更正确；使用者可自行修改映射表以适应自己的习惯。

## 质量校验清单

- [ ] 已先跑预览，确认改动清单无误伤
- [ ] 风格选择符合文档用途，且全文一致
- [ ] 改写后引用校验器全部通过
- [ ] 重要稿件改写前已有备份或版本提交

## 免责与边界

- 本工具按字符模式识别引用，正文里的数字组合存在被误判的可能（例如「第 3 章第 16 节」之外的表达）。预览清单就是用来人工把关的，请勿跳过。
- 不处理非 markdown 文件；不处理表格单元格之外的复杂排版结构（如嵌套引用块内需人工确认）。
- 改写不可逆，`--inplace` 前请确认已备份或已提交版本。
