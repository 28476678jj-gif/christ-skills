# 《基督教大辞典》知识库（christian-dictionary）

《基督教大辞典》（上海辞书出版社，2010）的深度精读检索库，供团队随时调取。

> **核对状态（2026-10-10）**：本书为纯扫描件（无文字层）。本库内容已用中文 OCR 引擎（rapidocr / PP-OCRv6）逐页识别并与扫描页脚核对；页码换算「正文第 p 页 → PDF 索引 = 71 + p」已经正文抽查验证。表中标注「已核对」者为扫描件原文，标注「词目表」者页码取自书前《词目表》。

## 使用方式

1. **先查体例**：读 `front-matter-notes.md`，了解 12 类分法、宗派立场、圣经版本规则。
2. **再查位置**：用 `structure-index.md` 的旗舰词条页码表（含核对状态）找到目标词条所在页。
3. **最后取义**：已核对词条直接读 `core-doctrines.md`；其余按「正文页 → PDF 索引 = 71 + 正文页」回原书查读。

## 重要边界（务必先读 `core-doctrines.md` 开头声明）

- 本库**忠实地呈现《基督教大辞典》的词条内容**，不是本库的教义判定。该辞典由天主教、新教、东正教学者合编，内容同时涉及三大传统及较小教派。
- 本库以**圣经（新教正典六十六卷）为最高权威**，以**使徒信经、尼西亚信经**为唯一强制锚点。
- 与信经一致者（三位一体、基督神人二性、复活等）本库认信；天主教、东正教特有的发展（如七件圣事、圣母敬礼、教宗权柄、圣像传统等）**显明标注为「传统立场」，不构成本库锚点**，当以圣经检验。
- 本辞典使用两套《圣经》版本：新教「和合本（新标准修订版简化字和合本）」与天主教「思高圣经学会译释版」。引用时请留意版本差异。
