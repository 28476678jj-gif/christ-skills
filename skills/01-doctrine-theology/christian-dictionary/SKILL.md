# 基督教大辞典检索技能

## 用途

当用户需要以下信息时触发：

- 查询《基督教大辞典》中某词条的定义、页码或所属大类。
- 了解天主教、东正教、新教对同一教义（如圣事、圣经正典、救赎）的不同表述。
- 快速定位核心教义词条（三位一体、上帝、圣经、圣灵、救赎等）的辞典原文与页码。
- 需要一部中性、综合、带页码来源的辞典式参考（讲章、教义笔记、信仰问答）。

## 输入与输出

- **输入**：用户提出的具体词条、教义主题，或「某词条在第几页」。
- **输出**：
  - 已 OCR 核对词条：给出 `core-doctrines.md` 精义摘要并标注正文页码。
  - 仅词目表有页码的词条：给出页码与提示「可按此页回原书查读（PDF 索引 = 71 + 正文页）」。
  - 未覆盖词条：说明收录范围，避免编造。

## 工作流程

1. **先查结构**：看 `structure-index.md` 的旗舰词条页码表（含核对状态）。
2. **再取释义**：已核对的读 `core-doctrines.md`；仅有页码的按正文页回原书读取（PDF 索引 = 71 + 正文页）。
3. **标注传统**：涉及天主教/东正教/新教差异的，注明「（某教传统立场）」。
4. **回归本库锚点**：以 `STATEMENT_OF_FAITH.md`（圣经最高权威，使徒信经与尼西亚信经为强制锚点）为边界。辞典表述与信经一致则确认；超出信经者（七件圣事、教宗权柄、圣母敬礼等）仅作「传统立场」呈现。
5. **核验经文**：引用圣经须用 `tools/verse_check.py` 校验，禁止凭记忆。

## 争议标注

回答时必须做到：

- **圣事/圣礼**：并述天主教、东正教「七件圣事」与新教「两项圣事」立场，指出为教派分歧点。
- **圣经正典**：新教 66 卷；天主教与东正教另收入若干次经（《多比传》《犹滴传》等）。
- **救赎论**：呈现奥古斯丁（赎价付魔鬼）与安瑟伦（偿付上帝）等不同历史解释。
- **教会论**：说明各派对大公教会、教宗权柄、主教制/长老制/会众制的不同理解。
- **原罪**：说明天主教「原初的义」概念与新教改革家的理解差异。

## 免责与边界

- 只提供《基督教大辞典》词条检索，不代替圣经学习、教会牧养或个人信仰判断。
- 未核对词条不编造内容，只给页码指引或说明「尚未收录」。
- 涉及具体教会、人物、当代事件（三自爱国运动、教宗任命等）按原文客观呈现，不附加政治或教派评价。
