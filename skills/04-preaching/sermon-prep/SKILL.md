# 讲章预备

## 用途

陪讲员走完从经文到讲台的全过程：先把经文读明白，提炼出一句话命题，搭出服从经文结构的大纲，再写成读得出口的逐字稿，并按时长校准篇幅。产出是一个讲章预备包：解经摘要、命题与大纲、逐字稿、时长估算。它是讲员的参谋与草稿，不替代讲员自己的祷告、消化与牧养判断。

## 触发场景

- "下周主日我讲 腓立比书 1:21，帮我预备"、"给我搭个讲章大纲，经文是……"
- "团契查经我带一段分享，15 分钟，经文……"
- "丧礼/婚礼/洗礼短讲，经文……，场合比较特殊"
- 不适用：只要解经研究不要讲章（用 expository-passage-study）；要主题式跨卷信息（先用 topical-bible-study 打底，再回到本技能聚焦成讲章）。

## 输入与输出

输入：

- 必需：经文范围。缺场合、受众、时长时，默认场合为主日崇拜、受众为一般信徒、时长 25 分钟，并在产出中注明默认值。
- 可选：场合（主日/团契/丧礼/婚礼/节期/布道会）、受众（信徒/慕道友/青少年/同工）、时长（分钟）、讲道传统（默认命题式，也可要求叙事式或第一人称式）。

输出（markdown，一个文件四部分）：

1. 解经摘要（一页内：经文全文、结构、背景一句话、主旨一句话）
2. 命题与大纲（命题一句话；2 至 4 个分点，每点附解释、例证、应用三要素）
3. 逐字稿（引言、分段正文、结论、回应引导、结束祷告方向）
4. 时长估算（按总字数换算分钟数）与上台提示（何处放慢、何处停顿、哪节经文须全文朗读）

## 工作流程

1. **确认输入。** 明确经文、场合、受众、时长。丧礼、婚礼、布道会等特殊场合，先确认对语气与内容边界的特殊要求。
2. **解经打底。** 按 expository-passage-study 的方法走一遍（结构观察、背景、词研、主旨），但压缩成一页摘要。**凡引用经文必须先检索取得原文（本地 biblemate 数据库或本库 `data/bibles/`），不得凭记忆引用**；解经摘要里只留对讲章有直接作用的观察，学术细节砍掉。
3. **提炼命题。** 一句话写出全篇讲章的命题（big idea）：能概括这段经文对今天会众的要求，且能被经文直接支撑。不合格命题的样子：三个词凑的标题党、放之四海皆准属灵口号、经文没说的感动。写不出合格命题就回到第 2 步，不许硬写。
4. **搭大纲。** 2 至 4 个分点，分点从经文结构里长出来（经文的段落、对比、递进就是分点），不得拿外在框架套经文（严禁"三股绳索""三个石头"这类硬凑）。每个分点配三样：解释（回到经文原意）、例证（见下）、应用（具体到本周可做的事）。例证规则：可用圣经内叙事、公认史实、普遍共同经验；不得虚构"我的一位朋友"式见证，不得编造数据与名人言论。
5. **写逐字稿。** 口述语言：每句话一口气说得完，长句拆短；避免书面腔与排比堆砌。引言从会众的真实处境切入，禁止以"今天我们来看"开头。结论必须回到福音：这段经文所显明的需要，如何被基督的位格与工作回应，然后给一个具体的当場回应（默想一个问题、做一个决定、彼此分享），不说教式喊口号。结尾附结束祷告的方向（要点，不写祷词全文，除非用户要求）。
6. **时长校准。** 中文讲道语速约每分钟 220 至 250 字，按目标时长反推逐字稿总字数（25 分钟约 5500 至 6200 字）。超出先砍例证与重复解释，不动经文呈现与应用；不足则加厚解释而非堆例证。
7. **自检交付。** 过一遍「质量校验清单」，标注朗读提示后交付，并提醒讲员：这份稿子需要他自己祷告消化，按他的声音重写一遍。

## 经文依据

- 提摩太后书 4:2：「务要传道，无论得时不得时，总要专心；并用百般的忍耐，各样的教训，责备人、警戒人、劝勉人。」讲道的核心动作是传道，不是分享感受。
- 彼得前书 4:11：「若有讲道的，要按着神的圣言讲」。讲章必须被经文约束，这是命题与大纲两步的根据。
- 哥林多前书 2:2：「因为我曾定了主意，在你们中间不知道别的，只知道耶稣基督并他钉十字架。」每篇讲章都要能回答：福音在哪里。
- 路加福音 24:27：「于是从摩西和众先知起，凡经上所指着自己的话都给他们讲解明白了。」任何经段的讲章最终都要讲到基督。
- 雅各书 3:1：「我的弟兄们，不要多人作师傅，因为晓得我们要受更重的判断。」讲道是受更重判断的事，这决定了本技能的克制：工具只做参谋，责任在讲员。

## 争议标注

- 讲道学传统有分歧（命题式、叙事式、第一人称式等），本技能默认经文驱动的命题式；用户指定其他传统时按其规范产出，并在文件中注明。
- 讲章内容触及争议级议题（如经文涉及预定、恩赐、末世解读）时，按 `DOCTRINE_POLICY.md` 在讲章中以牧者口吻并列要点或明确回避，不借讲台裁决宗派之争。
- 丧礼讲章若涉及未信者离世等敏感情形，聚焦安慰与盼望，不作个人永恒状态的论断。

## 质量校验清单

- [ ] 经文全文与全部引用来自检索，文件通过 `tools/verse_check.py`
- [ ] 命题一句话，且能被经文直接支撑
- [ ] 分点来自经文结构，无外在框架硬套
- [ ] 例证无虚构见证、无编造数据
- [ ] 逐字稿全部句子一口气读得完，引言不从"今天我们来看"开始
- [ ] 结论回到福音并给出具体回应
- [ ] 总字数与目标时长匹配（220-250 字/分钟）
- [ ] 争议议题已按政策处理
- [ ] 通过 `tools/lint_skill.py`

## 免责与边界

- 本技能产出为讲员的预备草稿，不构成可直接照读的成品。讲员须自己祷告、消化、按个人声音重写，并在会众面前为所传讲的内容负责（参雅各书 3:1）。
- 讲章中为说明而写的例证属于写作示范，讲员上台前应替换为真实经历或核实过的事实。
- 本技能不生成针对具体个人或教会的评判性信息；涉及教会内部事务的讲章需求，请由讲员自己与教会带领层确认分寸。
