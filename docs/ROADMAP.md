# 迭代路线图

这份文件回答三件事：每天更新什么、还要建哪些模块、对外推广时讲什么。它随项目调整，每次版本变更同步更新。

## 一、每日更新节奏

每天两件固定动作，加上按周轮换的内容主题。主日不发布新内容，只做读经与祷告，这条不作妥协。

**每日固定动作（每天必做）：**

1. 一个参考书细读单元（已有自动化，每天 08:00 执行，写入 `references/reading-notes/`，过经文校验后提交推送）
2. 当日灵修经文一篇（用 daily-devotion 技能产出，落 `devotions/` 目录，供当日推送与后续汇编）
3. 收尾同步：检查当日改动，整理摘要，提交推送（每天 21:00 自动执行）

**按周轮换的内容主题：**

| 星期 | 主题 | 当日做的事 |
|---|---|---|
| 一 | 经文查考 | 解经、主题查经类技能与内容，词研与原文工具 |
| 二 | 讲道与教导 | 讲章预备、讲章示例、小组带领材料 |
| 三 | 灵修与祷告 | 灵修默想、祷告指引、灵修日程 |
| 四 | 生活实践 | 婚姻亲子、职场、金钱、试探与自制 |
| 五 | 福音与见证 | 布道、慕道问答、见证整理 |
| 六 | 历史与人物 | 教会史、神学家、宗派谱系、古圣先贤注解 |
| 日 | 停更 | 不产出内容；只读经、祷告，收下周选题 |

例外情况按实际需要插入：发现经文引用错误、教义漂移或安全问题时，不受主题表约束，优先修。

## 二、功能模块清单

### 已可用

| 类目 | 技能 | 状态 |
|---|---|---|
| 02 解经 | expository-passage-study | 可用 |
| 03 主题查经 | topical-bible-study | 可用 |
| 04 讲道 | sermon-prep | 可用，附腓立比书 1:21 示例讲章 |

### 近期新增（按优先级）

1. **daily-devotion（每日灵修默想）**，07 祷告与灵修。用户给出当日经文或处境，产出默想、祷告指引、当日践行三步。已建，附 2026-10-02 示例。
2. **spiritual-encouragement（属灵勉励）**，13 教牧关怀。针对具体处境（疲乏、灰心、疾病、关系紧张、服事枯干）给出经文支撑的勉励，敏感级边界管理。已建。
3. **prayer-guide（祷告指引）**，07 祷告与灵修。按处境（感恩、认罪、代求、争战、就医、临终）生成祷告方向与经文支撑，不代祷者说话。
4. **devotion-plan（灵修日程生成）**，05 读经方法。按书卷或主题排出 N 天经文日程，每处检索核验存在性后输出。
5. **verse-of-day（当日经文）**，工具型。从日程或书卷顺序取当日经文，输出原文、上下文一句、一句默想提示。
6. **sermon-outline-small-group（小组版讲章大纲）**，04 讲道。把 sermon-prep 的产出压缩到 15 分钟小组版，含讨论题。

### 待优化

- `expository-passage-study`：增加「灵修化输出」选项，让研经结果能直接转成默想材料。
- `sermon-prep`：补特殊场合模板（丧礼、婚礼、洗礼）的语气与内容边界细则。
- 数据层：追加公有领域英文译本（WEB、KJV）做中英对照，用户本地版权译本仍走插件式。
- 工具层：增加 `tools/devotion_plan.py` 生成灵修日程；`verse_check.py` 支持一次校验整个 `devotions/` 目录。

## 三、推广时突出的核心价值

1. **经文可核验。** 所有引用必须经本地数据库检索，机器逐条比对，编造的经文通不过。市面上同类项目没有这道闸门，这是最硬的差别。
2. **教义有锚点。** 以普世信经为底线，核心教义持守立场，争议议题并列各宗派论证不作裁决，敏感类目强制具名人工审核。既不和稀泥，也不越权裁决。
3. **中文原生。** 六十六卷中文规范名、华人教会语境、小组带领场景，不是英文提示词的翻译品。
4. **版权干净。** 只收录公有领域文本，二次分发、改编、教学使用都不必担心侵权。
5. **场景即用。** 伴读、查经、讲章预备、灵修默想都有可直接照做的产出格式，附真实示例，不是空框架。

## 五、同步机制

- 内容改动：随做随提交，提交前 `git status` 查看清单，私人材料一律不进仓库。
- 每日 08:00 自动执行细读任务并提交推送（自动化 201263ba）。
- 每日 21:00 自动执行收尾同步（自动化：检查未提交改动、补当日摘要、推送）。
- 网络：先试直连，直连不通再试本地代理端口（近期观察：代理端口会变动，直连时通时不通）。
