# 深度精读笔记模板（六层辨析版 · 辨书优先）

每日细读按本模板输出，一本一档，文件名 `references/reading-notes/YYYY-MM-DD-<书名>.md`。
同一天读多本时，一天多档，不合并。

本模板落实老K 设定的「高级属灵学习助手」工作法：**六层阅读结构 + 真理/知识/经验三级标注**。
最高规范：圣经是信仰、教义、属灵生命判断的最高权威（sola Scriptura）。面对象征世俗思想须**辨书**，
既不因「来源世俗」就直接拒斥，也不因「讲得有道理」就直接认同。

## 辨书原则（最高优先，八项能力里最重要的一条）

> 基督徒读任何书——尤其世俗书、非基督徒作者的书——都容易落两个极端：
> ①「这是世俗的，所以不属灵」（直接拒斥）；
> ②「这本书讲得非常有道理，所以一定是对的」（直接认同）。
> 这两条都要避开。正确做法是一追到底：

**辨书四问（每本世俗/非基督徒作者的书都必须走一遍，写进第二层）：**

1. **真问题**：这本书讲出了什么真问题？（先把问题认准——问题可能是真实的，哪怕答案错了）
2. **答案**：它给出的答案是什么？（提炼作者实际主张，不只是他明说的标题）
3. **关系**：这个答案和圣经的答案有什么关系？（一致 / 部分一致 / 有张力 / 冲突 / 圣经未明确）
4. **底层世界观**：答案背后的人观、世界观、价值观是什么？系统对照圣经相关经文。

**示例（写进第二层作示范，不可省略对照经文）：**
商业书说「人要掌控自己的命运」→ 不能直接批判，也不能直接认同 → 追问背后「人观」：
人究竟是自己命运的主宰，还是受托人？圣经怎么看人的责任、神的主权？
- 雅各书 4:13-15（你们的生命不过是一片云雾；主若愿意，我们就可以活着，也可做这事）
- 箴言 16:9（人心筹算自己的道路，惟耶和华定夺他的脚步）
- 传道书（凡事都有定时，在日光之下劳碌有何益处）
这样才是真正的「基督徒阅读」：先把问题接住，再在圣经里找答案，最后才评断作者的答案。

## 三级标注（贯穿全文，每条重要结论都标）

- **【真理】** 圣经明确启示、普世教会共同持守的教义或命令。
- **【知识】** 可验证的事实、作者论点的梳理、学科结论。须再区分：事实 / 理论 / 解释 / 推论。
- **【经验】** 个人经历、作者见证、文化观察——仅供参考，绝不冒充真理。

严禁把【经验】当【真理】、把作者观点当圣经。无真实案例只写「实践建议」，不编造见证。

## 硬性要求

1. 六层结构齐全，不许缺层；第六层「牧养与输出」至少要给骨架或选题，不得空着。
2. **「辨书」为最高优先**：世俗/非基督徒作者的书，第二层必须走完辨书四问（真问题→答案→与圣经关系→底层世界观），
   并对照至少两处相关经文（如上面的雅各书/箴言/传道书示例）。基督徒作者的书也须做第三问「关系」判断，但四问强度可略减。
3. 「圣经锚定」层必须逐条给 A-E 判定与经文依据：
   - **A 与圣经一致**：（经文）
   - **B 部分一致**：（经文）一致在此，偏差在彼
   - **C 有张力**：（经文）张力点
   - **D 与圣经冲突**：（经文）须拒绝
   - **E 圣经未明确（开放）**：仅作实践建议，不升格为教义
4. 核心观点与逻辑框架用自己的话重述，不搬运原文长段（版权边界见 `CONTRIBUTING.md`）。
5. 引用原文只允许短句，必须带书内页或章节出处；经文引用注明译本与出处。
6. 写完必跑 `python tools/verse_check.py <笔记文件>`，错误与警告都要处理到 0。
7. 引用立场有张力的作者（莫特曼、巴特、田海华、倪柝声、白琦、陶恕部分命题等）时，
   按 `DOCTRINE_POLICY.md` 标注争议级，并在「圣经锚定」层标 C/D。
8. 跨学科整合层严格区分：科学事实 / 科学理论 / 哲学解释 / 个人推论，不得混为一谈。
9. 不伪造任何内容：页码、引文、数据、见证。做不到就如实写「实践建议」。

## 第一层 内容理解
（原五段之「核心观点」+「逻辑框架」合并升级）
- 作者真正要证明的那个命题（一到三句）。区分「他明说的主题」与「他实际论证的东西」。
- 全书论证骨架：按章节或论证步骤列出，说明作者为何这样排。
- 体例说明：讲章体 / 五问体 / 条目体 / 学术论述，及其效果。

## 第二层 思想辨析（辨书四问）
（世界观·人生观·价值观·人观·罪观·幸福观）
先避开两极端：①「世俗的，所以不属灵」直接拒斥；②「讲得有道理，所以一定对」直接认同。
- 真问题：这本书讲出了什么真问题？（问题本身可能真实）
- 答案：它给出的答案是什么？（提炼实际主张）
- 关系：答案与圣经答案的关系？（A 一致 / B 部分一致 / C 张力 / D 冲突 / E 开放）
- 底层世界观：答案背后的人观/世界观/价值观是什么？（对照经文，如雅各书 4:13-15、箴言 16:9、传道书）
示例参照：商业书「人要掌控自己的命运」→ 接住真问题（人确实需要主动担当）→ 查圣经神主权与人的责任。

- A 与圣经一致：（经文）

- D 与圣经冲突：（经文）须拒绝

（职场 / 金融 / 婚姻 / 心理 / 教育 / 文化，严格分层）
- 科学事实：（可验证）

- 哲学解释：（作者的价值观包装）
- 个人推论：（我的延伸，标【经验】）
