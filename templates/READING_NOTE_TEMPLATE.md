# 深度精读笔记模板（六层辨析版）

每日细读按本模板输出，一本一档，文件名 `references/reading-notes/YYYY-MM-DD-<书名>.md`。
同一天读多本时，一天多档，不合并。

本模板落实老K 设定的「高级属灵学习助手」工作法：**六层阅读结构 + 真理/知识/经验三级标注**。
最高规范：圣经是信仰、教义、属灵生命判断的最高权威（sola Scriptura）。面对世俗思想须辨析，
不因「有用」就当真理，也不因来源世俗就当错误。

## 三级标注（贯穿全文，每条重要结论都标）

- **【真理】** 圣经明确启示、普世教会共同持守的教义或命令。
- **【知识】** 可验证的事实、作者论点的梳理、学科结论。须再区分：事实 / 理论 / 解释 / 推论。
- **【经验】** 个人经历、作者见证、文化观察——仅供参考，绝不冒充真理。

严禁把【经验】当【真理】、把作者观点当圣经。无真实案例只写「实践建议」，不编造见证。

## 硬性要求

1. 六层结构齐全，不许缺层；第六层「牧养与输出」至少要给骨架或选题，不得空着。
2. 「圣经锚定」层必须逐条给 A-E 判定与经文依据：
   - **A 与圣经一致**：（经文）
   - **B 部分一致**：（经文）一致在此，偏差在彼
   - **C 有张力**：（经文）张力点
   - **D 与圣经冲突**：（经文）须拒绝
   - **E 圣经未明确（开放）**：仅作实践建议，不升格为教义
3. 核心观点与逻辑框架用自己的话重述，不搬运原文长段（版权边界见 `CONTRIBUTING.md`）。
4. 引用原文只允许短句，必须带书内页或章节出处；经文引用注明译本与出处。
5. 写完必跑 `python tools/verse_check.py <笔记文件>`，错误与警告都要处理到 0。
6. 引用立场有张力的作者（莫特曼、巴特、田海华、倪柝声、白琦、陶恕部分命题等）时，
   按 `DOCTRINE_POLICY.md` 标注争议级，并在「圣经锚定」层标 C/D。
7. 跨学科整合层严格区分：科学事实 / 科学理论 / 哲学解释 / 个人推论，不得混为一谈。
8. 不伪造任何内容：页码、引文、数据、见证。做不到就如实写「实践建议」。

## 模板

```
# YYYY-MM-DD 深度精读：《书名》

- 作者 / 译者 / 出版 / 版本
- 阅读范围：全本或第 X 章（书内页 X-Y，PDF X-Y）
- 读取方式：文字层直接提取 / 扫描件渲染 / epub 转文本
- 一字未读的部分（如有）要写明
- 争议级（如有，按 DOCTRINE_POLICY）

## 第一层 内容理解
（原五段之「核心观点」+「逻辑框架」合并升级）
- 作者真正要证明的那个命题（一到三句）。区分「他明说的主题」与「他实际论证的东西」。
- 全书论证骨架：按章节或论证步骤列出，说明作者为何这样排。
- 体例说明：讲章体 / 五问体 / 条目体 / 学术论述，及其效果。

## 第二层 思想辨析
（世界观·人生观·价值观·人观·罪观·幸福观）
- 作者隐含或未明说的预设是什么？他的「人是什么」「问题根源是什么」「出路是什么」。
- 与圣经人性论、创造论、原罪论对照，点出可借鉴与须警惕处。
- 世俗来源（心理学 / 哲学 / 管理学）被使用时，标明其边界。

## 第三层 圣经锚定（A-E 分级 + 经文依据）
逐条主张对应：
- A 与圣经一致：（经文）
- B 部分一致：（经文）一致在此，偏差在彼
- C 有张力：（经文）张力点
- D 与圣经冲突：（经文）须拒绝
- E 圣经未明确（开放）：仅作实践建议
每条给和合本经文依据，必要时注原文词义（如 chriō / piplēmi）。

## 第四层 跨学科整合
（职场 / 金融 / 婚姻 / 心理 / 教育 / 文化，严格分层）
- 科学事实：（可验证）
- 科学理论：（可错，标注）
- 哲学解释：（作者的价值观包装）
- 个人推论：（我的延伸，标【经验】）
说明哪些可直接转译为信仰实践，哪些须设边界。

## 第五层 生命实践
认知 → 行为 → 关系 → 生命改变，四步各给 1-2 条可操作项。
对应 taxonomy 类目；可做成自测清单 / 辅导路径 / 查经设计。

## 第六层 牧养与输出
至少一项产出的骨架或选题：
- 讲章骨架 / 查经设计 / 小组讨论题 / 门训单元 / 课程大纲 / 文章或口播选题
- 注明目标受众与核心经文。

## 附：金句摘录（≤6 条）
每条带书内页或章节出处；经文引录另起，注明译本。
```
