# 深度精读笔记模板

每日细读按本模板输出，一本一档，文件名 `references/reading-notes/YYYY-MM-DD-<书名>.md`。
同一天读多本时，一天多档，不合并。

## 硬性要求

1. 五段结构齐全，不许缺项；「值得存疑或反驳之处」不得写「暂无」之类敷衍话，必须给出至少一条实质性的批评或辨读。
2. 核心观点与逻辑框架用自己的话重述，不搬运原文长段（版权边界见 `CONTRIBUTING.md`）。
3. 引用原文只允许短句，必须带书内页或章节出处。
4. 写完必跑 `python tools/verse_check.py <笔记文件>`，错误与警告都要处理到 0。
5. 引用立场有张力的作者（莫特曼、巴特、田海华、倪柝声、白琦等）时，按 `DOCTRINE_POLICY.md` 标注争议级。

## 模板

```
# YYYY-MM-DD 深度精读：《书名》

- 作者 / 译者 / 出版 / 版本
- 阅读范围：全本或第 X 章（书内页 X-Y，PDF X-Y）
- 读取方式：文字层直接提取 / 扫描件渲染 / epub 转文本
- 一字未读的部分（如有）要写明

## 一、核心观点

作者真正要证明的那一个命题，一到三句说清。区分「他明说的主题」和「他实际在论证的东西」。

## 二、逻辑框架

全书的论证骨架，按章节或按论证步骤列出。要能看出作者为什么这样排，而不是罗列目录。
若是讲章体、五问体、条目体，点明体例并说明其效果。

## 三、关键论据与案例

按框架逐条填，每条写：论据/案例本身 + 作者用它证明了什么 + 我对其效力的判断。
经文引用注明出处；比喻和意象单独摘出，因为它们是最可复用的部分。

## 四、可落地的启发

具体到「能用在哪」：对应 taxonomy 的哪几个类目、可以做成什么（自测清单、讲章骨架、
辅导对话路径、查经设计），以及转译到今日处境时需要换掉什么。

## 五、值得存疑或反驳之处

至少一条实质性批评。可从这些角度找：论证是否循环或重复计数、经文是否被讲章式联想
而非解经、神学立场是否有张力、是否有文化时代限制、是否遗漏了相反的圣经材料。

## 附：金句摘录（≤6 条）

每条带书内页或章节出处。经文引录另起，注明译本。
```
