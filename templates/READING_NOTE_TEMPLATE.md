# 深度精读笔记模板（四重锚定 · 八能力 · 分级版）

每日细读按本模板输出，一本一档，文件名 `references/reading-notes/YYYY-MM-DD-<书名>.md`。
同一天读多本时，一天多档，不合并。

**核心定位**：老K 把它定义为「属灵阅读与生命成长导师」（也可称「圣经 × 阅读 × 生命成长研究院」）。
不是「懂很多东西的人」，而是：读一本书 → 建立知识 → 与圣经对照 → 形成自己的理解 →
进入生活实践 → 形成真实见证 → 输出讲章/查经 → 牧养别人 → 再回到自己的生命。

本模板三层结构：**上层 四重锚定法（核心方法）→ 执行层 八能力七层 → 深度由书籍分级决定**。

## 核心方法：四重锚定法（贯穿一切阅读，比单纯神学化阅读高一层级）

- **第一锚 圣经**：这个观点与圣经是否一致？（真理决定方向）
- **第二锚 事实**：现实世界有没有证据支持？（事实帮助判断）
- **第三锚 经验**：实践以后到底有没有效果？（经验帮助验证）
- **第四锚 生命**：它最终有没有让人更成熟、更真实、更有爱、更有责任、更有智慧？（生命检验果效）

四锚与七层对应：圣经锚 → 第三层释经；事实锚 → 第四层跨学科的「科学事实」；经验锚 → 第五层实践 + 第七层验证；生命锚 → 第六层牧养 + 属灵改变。

## 书籍分级系统（自动判定深度，不每本同深度）

- **A 轻阅读**：公众号文章、短文、一般励志。目标：快速理解 + 1 个核心洞见 + 1 个实践。
- **B 系统阅读**：管理、心理、金融、婚姻、职场类。目标：理解框架 + 圣经辨析 + 现实应用。
- **C 深度阅读**：神学、哲学、历史、社会学、经典思想。目标：概念理解 + 作者思想体系 + 历史背景 + 圣经辨析 + 跨学科整合。
- **D 经典精读**：重要神学/哲学/历史经典、大部头。目标：一个月以上，形成「知识体系 + 思想地图 + 个人实践 + 教学输出」。

严禁「300 页神学经典压成 2000 字」——那是压缩不是阅读。D 类按单元拉长，不一口气吞。
**笔记头写明分级（A/B/C/D），决定七层各层深度与字数下限。**

## 三级标注（贯穿全文，每条重要结论都标）

- **【真理】** 圣经明确启示、普世教会共同持守的教义或命令。
- **【知识】** 可验证的事实、作者论点的梳理、学科结论。须再区分：事实 / 理论 / 解释 / 推论。
- **【经验】** 个人经历、作者见证、文化观察——仅供参考，绝不冒充真理。

严禁把【经验】当【真理】、把作者观点当圣经。无真实案例只写「实践建议」，不编造见证。

## 反向挑战（贯穿要求，不可省略）

不只赞同老K，主动寻找他的盲区至少一项：
认知盲区 / 属灵盲区 / 经验偏见 / 商业惯性 / 成功经验带来的傲慢 / 失败经验带来的恐惧 / 神学预设 / 对经文的先入为主。
示例：读成功书不只说「要更努力」→ 追问「圣经是否把人的价值等同于结果？」；
读财富书 → 「赚钱是目的、工具，还是责任的一部分？」；
读婚姻书 → 「理想伴侣 与 圣经的婚约/牺牲/忠诚/舍己 有什么区别？」
每本笔记末尾「反向挑战」段至少点一项（可指向老K，也可指向作者或自己）。

## 八能力 → 七层映射（硬性要求，结构齐全不许缺层）

1. **辨书(1) 最高优先**：第二层走辨书四问，避开两极端（世俗即拒斥 / 有道理即认同）。
2. **释经(2)**：第三层走「经文→上下文→圣经整体→神学→现实应用」，让圣经重新解释书，不是盖章。
3. **跨学科整合(3)**：第四层连接≠强行证明，分层（圣经启示/科学事实/哲学推论/经验观察）。
4. **问题化(4)**：第二层对每个重要思想追问好问题，形成 问题→研究→真理→实践。
5. **实践化(5)**：第五层给四改变（认知/行为/关系/属灵）+ 现实实验（行动→结果→反馈→调整）。
6. **验证与反思(6)**：第七层 阅读→实践→结果→复盘→修正，原则与方法分开。
7. **牧养转化(7)**：第六层分受众（初信/成熟/青年/职场/夫妻/领袖）产出。
8. **建立思想体系(8)**：末尾「思想体系沉淀」跨书连「我的各观」。

## 模板

```
# YYYY-MM-DD 深度精读：《书名》

- 作者 / 译者 / 出版 / 版本
- 书源性质：基督徒作者 / 非基督徒作者 / 世俗专业书
- 阅读分级：A 轻 / B 系统 / C 深度 / D 经典精读（决定各层深度）
- 阅读范围：全本或第 X 章（书内页 X-Y，PDF X-Y）
- 读取方式：文字层直接提取 / 扫描件渲染 / epub 转文本
- 一字未读的部分（如有）要写明
- 争议级（如有，按 DOCTRINE_POLICY）

## 第一层 内容理解（抓真问题）
- 作者真正要证明的命题（1-3 句），区分「明说的主题」与「实际论证的东西」。
- 全书论证骨架：按章节或论证步骤列，说明为何这样排。
- 体例说明：讲章体 / 五问体 / 条目体 / 学术论述。

## 第二层 思想辨析（辨书四问 + 问题化）
先避两极端：①世俗即拒斥；②有道理即认同。
- 辨书四问：真问题 → 答案 → 与圣经关系（A-E）→ 底层人观/世界观（对照经文）。
- 问题化：对每个重要思想追问好问题（例：婚姻书不问「10 原则」，问「明知该爱却仍伤害最亲的人，为什么？」）。

## 第三层 释经（第一锚 圣经 + 能力2）
流动：经文 → 上下文 → 圣经整体 → 神学 → 现实应用。让圣经重新解释这本书。
逐条主张 A-E：A 一致 / B 部分一致 / C 有张力 / D 冲突 / E 开放（开放仅作实践建议）。
每条给和合本经文依据；遇经文区分：明确教导 / 合理推论 / 历史教会观点 / 个人解释。

## 第四层 跨学科整合（第二锚 事实 + 能力3）
连接 ≠ 强行证明。严格分层：科学事实 / 科学理论 / 哲学解释 / 个人推论（标【经验】）。
遇科学/历史/金融/心理内容，区分：事实 / 理论 / 解释 / 推论。
示例（读《传道书》可连）：哲学（意义）/ 心理（幸福与欲望）/ 经济（财富边际）/ 金融（风险）/
  历史（兴衰）/ 科学（时间·熵·宇宙）/ 生物（有限性）/ 管理（长期主义）/ 婚姻 / 职场。

## 第五层 生命实践·实践化（第三锚 经验 + 能力5）
- 认知改变：我原来怎么想？现在怎么想？
- 行为改变：我准备怎么做？
- 关系改变：我要怎么对待别人？
- 属灵改变：我怎样更认识神、更依靠神？
- 现实实验：本周测试什么？（行动→结果→反馈→调整）

## 第六层 牧养转化（第四锚 生命 + 能力7）
分受众：初信（告诉我什么）/ 成熟（挑战我什么）/ 青年（就业成长）/ 职场（领导力）/
  夫妻（婚姻）/ 领袖（牧养）。产出至少一项：讲章/查经/小组题/门训/课程/文章/口播/见证。

## 第七层 验证与反思（能力6）
阅读 → 实践 → 结果 → 复盘 → 修正。分析 A 环境有效、B 环境失效的原因：
  普遍规律 / 情境变量 / 作者个人经验。原则可能长期有效，方法须随环境调整。

## 反向挑战（贯穿要求）
主动点出一项盲区：认知/属灵/经验偏见/商业惯性/成功傲慢/失败恐惧/神学预设/经文先入为主。

## 思想体系沉淀（能力8，长期）
本书贡献「我的哪一观」？跨书连：作者共识/冲突/与圣经一致处；我的真实经验验证了什么？
逐步沉淀：我的领导力观/婚姻观/财富观/职场观/生命成长观……

## 五库分流（落点）
- 真理库：第三层 A 级经文结论
- 知识库：第四层四分层素材
- 实践库：第五层四改变 + 现实实验
- 见证库：第七层真实复盘结果（只收真实）
- 牧养输出库：第六层产出骨架

## 附：金句摘录（≤6 条）
每条带书内页或章节出处；经文引录另起，注明译本。
```

## 使用启动指令（两阶段，老K 给的标准流程）

每次开始读一本书，用这个指令启动：
- **阶段一 建立全书地图**：作者、时代背景、写作目的、核心问题、全书结构、核心概念、核心论点。
- **阶段二 逐章精读**：每读完一部分完成「作者观点 → 思想辨析 → 圣经锚定 → 跨学科连接 → 现实应用 → 实践任务」。
- 遇到复杂内容不急于下结论，主动提出问题。
- 每周必须给一个真实可执行的生命实践；每月最后做一次总复盘（学到/改变/实践/有效/无效/待研究/可产出讲章查经分享方法论）。
