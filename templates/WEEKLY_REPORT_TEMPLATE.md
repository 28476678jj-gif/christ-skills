# 每周读书报告模板

每周最后产出一份，汇总本周精读（可跨多本书、多个单元）。文件名
`references/reading-notes/YYYY-Www-周报.md`（Www 如 W40）。

> 定位：这是「月度闭环」的周节点——读书 → 辨析 → 圣经 → 实践 → 记录 → 复盘 → 教别人。
> 不是「读书 → 总结 → 结束」。真正把书吃进身体里的方式是：实践它，再重新理解它。

- 本周核心问题：

## 十八问

一、这部分内容到底讲了什么？
二、作者最重要的 3—5 个观点是什么？
三、作者背后的世界观是什么？
四、哪些观点与圣经一致？
五、哪些观点与圣经存在张力？
六、有哪些经文可以帮助我们重新理解这个问题？
七、它与历史、哲学、科学、金融、职场、婚姻、家庭、人生有什么联系？
八、这部分内容对我的生命提出了什么挑战？
九、我本周必须实践哪几件事？
十、我需要观察什么结果？
十一、有哪些真实案例可以印证或反驳？
十二、能不能形成一篇讲章？
十三、能不能形成一次查经？
十四、能不能形成一次小组分享？
十五、能不能形成一篇文章或一条口播？
十六、我本周最大的属灵亮光是什么？
十七、我有哪些地方仍然不明白？
十八、下周需要继续研究什么？

- 【本周最值得实践的行动】：

- 【本周一个真实生命改变记录】：（只有真实发生过的才写；没有就写「暂无真实记录」，不得编造）

## 反向挑战（写周报时一并自检）

对照本周内容，主动寻找自己的盲区，至少点出一项：
- 认知盲区 / 属灵盲区 / 经验偏见 / 商业惯性
- 成功经验带来的傲慢 / 失败经验带来的恐惧
- 神学预设 / 对经文的先入为主
（例：读成功类书不只说「要更努力」，而追问「圣经是否把人的价值等同于结果？」；
读财富类书追问「赚钱是目的、工具，还是责任的一部分？」；
读婚姻类书追问「理想伴侣 与 圣经的婚约/牺牲/忠诚/舍己 有何区别？」）
