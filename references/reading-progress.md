# 参考书细读进度

规则（2026-10-02 老K 要求；2026-10-03 起逐层升级：六层辨析版 → 八能力版 → 四重锚定·八能力·分级版）：

1. **每天至少完成 2 本书的深度精读**，不是浏览。长的书按单元推进（一个单元 = 一个完整章节或 PDF 15-25 页），短的书一次读完整本。
2. 每本按 `templates/READING_NOTE_TEMPLATE.md` 的**六层结构**出笔记：内容理解 → 思想辨析 → 圣经锚定（A-E 分级 + 经文依据）→ 跨学科整合 → 生命实践 → 牧养与输出。全文贯穿【真理】/【知识】/【经验】三级标注，严禁把经验当真理、作者观点当圣经。第六层「牧养与输出」不得空着。
3. 按 `BIBLIOGRAPHY.md` 出现顺序轮选，损坏或格式不支持的跳过并记原因。
4. **优先选有文字层的书**（提取便宜、读得深、能通读全本）；扫描件每次只渲染当天要读的那十几页，不整本渲染。（注：当前模型不支持读图，扫描件逐页精读需换多模态模型或等支持，详见下方「读取方式备忘」。）
5. 笔记写完必跑 `tools/verse_check.py`，错误与警告都处理到 0 才能提交。
6. **辨书原则（最高优先，八项能力第 1 条）**：读任何书——尤其世俗/非基督徒作者的书——不能落两个极端（①「世俗的，所以不属灵」直接拒斥；②「讲得有道理，所以一定对」直接认同）。正确做法走辨书四问：①这本书讲出了什么真问题？②它给的答案是什么？③答案和圣经答案有什么关系？④答案背后的人观/世界观/价值观是什么（系统对照雅各书 4:13-15、箴言 16:9、传道书等）。模板第二层已写死四问+商业书「人要掌控自己的命运」示例，笔记必须照做。书源性质字段（基督徒/非基督徒/世俗专业书）写在笔记头，决定四问强度。
7. **释经（能力 2）**：所有重要思想都要回到圣经重新定位。走「经文 → 上下文 → 圣经整体 → 神学 → 现实应用」的流动，目标是**让圣经重新解释这本书**，不是拿圣经给书盖章。例：书讲「人的核心需求是被认可」→ 继续查圣经怎么看人的身份、尊严、骄傲、神的接纳与人的认可之别。
8. **跨学科整合（能力 3）**：放进更大知识世界（神学/金融/理财/婚姻/家庭/职场/管理/历史/科学/哲学/地理/生物/宇宙等），但**连接 ≠ 强行证明**。科学就是科学、哲学就是哲学、圣经就是圣经，明确分层：圣经启示 / 科学事实 / 哲学推论 / 经验观察，不是同一层级。模板第四层以《传道书》为例列了十类连接。
9. **问题化（能力 4）**：把「知识」变成「问题」。每个重要思想不只记答案，要追问一个真正的好问题（例：婚姻书不问「10 个原则」，而问「人明知该爱却仍伤害最亲的人，为什么？」继续追性格/原生家庭/欲望/自我中心/罪/结构）。形成 问题 → 研究 → 真理 → 实践。第二层须照做。
10. **实践化（能力 5）**：每本书必须进现实生活，不能停在「读完了所以懂了」。第五层给四改变（认知/行为/关系/属灵）+ 至少一个现实实验（行动→结果→反馈→调整）。例：领导力——本周先问三个问题再指出员工问题。
11. **验证与反思（能力 6）**：不允许「读完即真理」。建立 阅读→实践→结果→复盘→修正 闭环；分析为什么 A 环境有效、B 环境失效，区分普遍规律 / 情境变量 / 作者个人经验。原则和方法分开：原则可能长期有效，方法须随环境调整。列为第七层。
12. **牧养转化（能力 7）**：学到的东西要变成帮助别人生命成长的工具。第六层按受众拆分（初信/成熟/青年/职场/夫妻/领袖），产出讲章/查经/小组题/门训/课程/文章/口播/见证。核心原则：知识不是终点，牧养才是出口。
13. **建立思想体系（能力 8，最高一层）**：不是读 100 本，而是最终形成「自己的体系」。跨书主动连接（作者共识/冲突/与圣经一致处），逐步沉淀我的领导力观/婚姻观/财富观/职场观/生命成长观……汇总为「圣经 × 人生 × 商业 × 家庭 × 职场 × 财富 × 生命成长」体系（未来写书的真材实料）。模板末尾「思想体系沉淀」机制落实。
14. **四重锚定法（核心方法，贯穿一切）**：每本笔记用四锚校验——第一锚 圣经（与圣经是否一致，定方向）/ 第二锚 事实（现实有无证据，助判断）/ 第三锚 经验（实践后有无效果，助验证）/ 第四锚 生命（是否让人更成熟真实有爱有责任有智慧，验果效）。比单纯神学化阅读高一层级；四锚对应七层见模板。
15. **书籍分级（不每本同深度）**：每本自动判 A 轻 / B 系统 / C 深度 / D 经典精读，写进笔记头，决定七层深度与字数下限。A=快速理解+1洞见+1实践；B=框架+圣经辨析+应用；C=概念+作者体系+历史背景+辨析+整合；D=≥1 月，知识体系+思想地图+实践+教学输出。严禁「300 页神学经典压成 2000 字」式压缩，D 类拉长按单元推进。
16. **每周读书报告**：每周最后按 `templates/WEEKLY_REPORT_TEMPLATE.md` 产出（含十八问 + 五个固定输出项 + 反向挑战自检）。文件名 `references/reading-notes/YYYY-Www-周报.md`。
17. **月度闭环**：读书 → 辨析 → 圣经 → 实践 → 记录 → 复盘 → 教别人（不是读书→总结→结束）。每月最后一周做总复盘：学到/改变/实践/有效/无效/待研究/可形成哪些讲章查经分享方法论。真正吃进书的方式是实践后再重新理解。
18. **反向挑战（主动找盲区）**：不只读赞同。每本笔记末尾「反向挑战」段至少点一项：认知/属灵盲区、经验偏见、商业惯性、成功傲慢、失败恐惧、神学预设、对经文先入为主。示例见模板（成功书/财富书/婚姻书的追问）。
19. **五库沉淀**：按 `references/FIVE_LIBRARIES.md` 把笔记分流进 真理库/知识库/实践库/见证库/牧养输出库。见证库只收真实发生过的，禁编造。闭环：圣经给方向、知识给视野、实践给答案、经历给见证、牧养给使命。
20. **启动指令两阶段**：开读用标准流程——阶段一先建全书地图（作者/时代背景/写作目的/核心问题/结构/核心概念/论点）；阶段二逐章精读，每部分完成「作者观点→思想辨析→圣经锚定→跨学科连接→现实应用→实践任务」。复杂内容不急于下结论，主动提问；经文区分明确教导/合理推论/历史教会观点/个人解释；科学等内容区分事实/理论/解释/推论。
